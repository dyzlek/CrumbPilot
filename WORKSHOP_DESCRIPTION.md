# CrumbPilot

Cookie Clicker automation with a block-based Script Studio. Made by Moxolote.

- Big cookie autoclick: 0–1,000 CPS
- Separate golden and wrath cookie controls
- Independent building and regular-upgrade auto-buy timers, accurate to the second
- Up to 20 named visual scripts, with multiple scripts running at once
- Building, upgrade, wait, If/Else, and repeat blocks
- Move, copy, and edit blocks directly in the studio
- Movable, minimizable control panel and saved settings

Open **Script Studio** from the in-game panel. Choose blocks from the palette and press **Run this script**. Start with `Building → Wait → Repeat` for a simple purchase loop.

`Alt+E` toggles big-cookie autoclick. `F7` stops big-cookie autoclick. Other enabled features have their own controls.

The mod uses the old internal ID `Car Clicker` to preserve existing saves. Steam achievements are disabled while the mod is enabled.
